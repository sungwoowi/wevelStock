## 응답 형식 (반드시 준수)

다음 키를 **최상위**에 가진 단일 JSON 객체로만 응답하세요. 마크다운 코드블록이나 다른 텍스트 없이 JSON만.

```
{{
  "verdict": "positive" | "neutral" | "caution" | "alert",
  "confidence": 0-100 사이 정수,
  "reasons": [
    "근거 1 (구체적이고 데이터에 기반)",
    "근거 2",
    "근거 3 (최소 3개, 권장 5-7개)"
  ],
  "narrative": "종합 판단 서술 — 단기/장기 전망, 섹터 흐름, 주의사항을 포함한 2-4문단"
}}
```

## 답변 가이드
1. **단기(1-2주)와 장기(3개월+)를 narrative에 분리** 명시
2. **reasons에는 구체적 수치 포함** (예: "KOSPI -0.37%, 반면 AI반도체 +3.3%")
3. **verdict 선택 기준**:
   - `positive`: 전반적 매수 우호, 상승 모멘텀 뚜렷
   - `neutral`: 혼조, 섹터별 차별화, 관망 권고
   - `caution`: 경계 요인 증가, 비중 축소 검토
   - `alert`: 명확한 리스크, 즉시 방어 필요
4. **confidence**: 데이터 완전성 + 판단 명확성을 종합. mock 데이터가 섞여 있으면 낮게.
