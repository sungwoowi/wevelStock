## 2. 채팅이 "함수자판기"였던 이유 (감사 결과)

| 원인 | 실물 증거 | 조치 |
|---|---|---|
| 최종 답변을 "압축기"가 생성 | 프롬프트 원문이 "당신은 자연어 답변 **압축기**입니다 · 결론 ≤3줄" + 가장 작은 모델 + 800토큰 제한 | ✅ **오늘 해소** — 임원 모드 기본화 |
| 진짜 어드바이저(임원)가 이미 있는데 스위치 꺼짐 | "점수 합산 기계가 아니다 · 시나리오 3개 · 행동 지침" 페르소나 존재, 채팅 탭 미배선 | ✅ config 스위치로 켬 (`chat.executive_mode_default`) |
| 위→아래 상쇄 배선 | 분석가에 코드라벨 병기 **강제** ↔ 최종단에서 3겹 장치로 **제거** | P3b 에서 페르소나 정리와 합본 |
| 내용이 30일간 "관망" 단일음 (96~100%) | kill switch 가 전 종목 같은 답 → 형식이 좋아도 자판기 체감 | BRAIN 로드맵(다른 세션) 소관 |
| 지식이 규칙표 + 3개 부서는 0바이트 | canon 36 카테고리 중 26 빈 폴더 | P1 지식 반입으로 충전 |

참고: 같은 모델이 쓰는 브리핑 내러티브는 유창함 → **모델 문제가 아니라 배선 문제**라는 실증.

## 3. 외부 벤더 실측 비교 — 무엇을 차용하고, 무엇은 우리가 우위인가

| 항목 | prism-insight (실측) | stock-analyzer | wevelStock 현재 | 차용/판정 |
|---|---|---|---|---|
| 구조 | **깔때기**: 결정론 트리거 → 최종 3종목 → 13 에이전트 심층 | 카테고리별 이슈 해석 → 추천 | 위원회: 모든 종목×양트랙 | 🔵 **깔때기 차용** (부품은 이미 보유) |
| 압축기 | 공통필터→6트리거→점수→탑다운 슬롯→3종목 (100% 결정론) | — | 큐레이션→트리거→rank_candidates 5종목 + **백테스트 edge** | 🟢 **대등 이상** — 탑다운 슬롯만 차용 |
| 탑다운(섹터→종목) | LLM 매크로가 준 주도섹터로 필터 + 장세별 슬롯(강세 2탑/1바텀 등) | — | 섹터 신호 계산은 되나 종목 선별에 **미배선** | 🔵 **차용** (P3a) |
| 심층 분석 | 생존 3종목에 시장·산업·재무·뉴스·기술 풀 리포트 | 이슈 해석 리포트 퀄리티 높음 | 생존 5종목에 잘린 재료로 YAML → "관망" | 🔵 **차용** (P3b — 임원식 리포트) |
| 뉴스/검색 | Perplexity+Firecrawl **월 $35 유료 검색** | 시장심리·트렌드·정책·거시 카테고리 해석 | 수집·분류·격상까지 완성, **능동 검색 없음** | 🔵 검색축 신설 후보 / 해석 카테고리 참고 |
| 복기 | "승률 자동 반영"은 홍보 문구 — 실제 **수동** | — | 미착수 (track record 0) | 🟣 **우리가 넘어설 지점** — 자동 채점 루프 |
| 수급·파동 | 없음 | 없음 | WAVE-ALPHA 21명제 + 5주체 수급 + 신고가·가격수급 자료 | 🟢 **우리만의 무기** (공간축 종목 단계) |
| 비용 | **$310/월** (분석가 13개인데 감당되는 이유 = 깔때기) | ? | ~$34/월인데 비용 경보 (이유 = 위원회 패턴) | 깔때기가 비용의 구조적 해법 |
| 성과 검증 | 모의 +244.63% **공개** (86건, 승률 45.4%) | 일일 리포트 공개 | 검증 0 | 🔵 공개 track record 방식 차용 |

핵심 교훈: **프리즘은 "위원회 무죄론"이 아니라 "깔때기 유죄론의 반증"** — 위원회를 두려면 깔때기 안쪽(생존 소수)에 둬라. 그리고 프리즘의 13개 중 절반은 판단이 아니라 리포트 분업(요약·품질평가·번역)이다.

## 4. 현재 구조 → 바꿀 구조

| | 현재 (위원회) | 이후 (소프트 깔때기) |
|---|---|---|
| 흐름 | 모든 종목 × 양트랙에 전원 의견 → 취합 | 시장 게이트 → 섹터 → 종목 압축 → **생존 3~5종목만** 심층 |
| 게이트 성격 | kill switch 가 잘라버림 (하드) | 게이트는 **기본값+이유+잘린 것 요약**을 발행, 심층 LLM 이 사실 근거로 뒤집기 가능 + 역발상 예외 레인(PANIC-REVERSAL) |
| 판단 LLM | 채팅 1회 최대 ~11콜 (분류 1 + 분석가 프리페치 최대 6 + 전략가 2 + 압축기 1~2) | **판단 1~2콜 + 복기 1콜(분리 필수)** + 뉴스 분류 마이크로콜. 1개로 접을지는 채점 데이터로 결정 |
| 페르소나 13개 | 각자 verdict 발행하는 인격 | 판단자·복기자 프롬프트의 **렌즈 섹션**으로 접힘 (삭제 아님) |
| 지식부 9 | 유지 | 유지 — 서재. 깔때기 단계가 자료를 선별 주입 (프롬프트 비대 방지) |
| 규칙 | 프롬프트에 산문으로 강제 (추종 희석) | **코드로** (7계명·게이트·심법 수치 — 이미 이 방향), LLM 은 해석·예외·서사만 |
| 출력 | YAML + 점수 나열 → 3줄 압축 | 시장/섹터/종목 **단계별 구조화 + 통찰 서사** (복기 귀속 가능) |
| 구조 변경 | 매번 세션 논의 + 코드 수정 | 자료는 드롭→정제→승인(P1), 구조는 레지스트리 데이터(P4), 통폐합은 채점 근거 PROPOSAL→승인(P5) |

### 기각한 것 (오늘 명시적으로 버린 선택지)

| 기각 | 이유 |
|---|---|
| 전면 재건축 (분석가/전략가 폐기 후 신축) | 1,430 테스트·계약 폐기 + "설계 방대·루프 미완" 패턴 재발. 부품 70~80% 재사용 가능 |
| 하드 깔때기 (결정론이 자르면 끝) | 07-03 SK하이닉스 실증 — 통찰(주도주 패닉=기회)이 시스템 밖에서만 적중. 킥의 제도적 말살 |
| 단일 LLM 빅뱅 통합 | 판단 2콜 유지 → 채점 데이터 보고 접기. 복기 LLM 은 영구 분리(자기 채점 오염) |
| LLM 무허가 자가 개편 | 채점(적합도 함수) 없는 진화 = 무작위 표류. PROPOSAL→사용자 승인→데이터 반영만 허용 |
| 범용 워크플로 엔진 (배선 전부 데이터화) | inner platform 함정. 레지스트리는 기존 manifest 패턴의 제한 확장까지만 |

## 5. 5축 ↔ 현재 자산 — 어디가 차 있고 어디가 비었나

| 축 | 이미 있음 | 비어 있음 | LLM vs 코드 |
|---|---|---|---|
| 공간 1단 (시장 타이밍) | regime·kill switch·VIX/breadth·박종훈 변곡점 | 유동성 게이지(예탁금·신용·M2) | 게이트=코드 / 예외 뒤집기=LLM |
| 공간 2단 (섹터 자금) | 강세섹터 ETF·순환매 방향 계산 | **섹터별 수급 데이터 + 종목 선별 배선** | 감지=코드 / "왜 도나" 서사=LLM |
| 공간 3단 (주도주) | S-Score·MA-ride·신고가·α + 백테스트 edge | 사이클 게이지(신고가=100) — Tier 2 예정 | 스크리닝=코드 / 선택=LLM |
| 시간축 | Track A/B + 타임프레임 철학 확정 | (렌즈가 아니라 2배 비용 위원회로 구현된 것만 문제) | 코드 (라우팅 파라미터) |
| 뉴스/검색축 | 수집·분류·격상·해석 M1 | **능동 검색** + 해석 콜 사고예산 0 문제 | 수집·분류=코드+싼LLM / 해석=LLM |
| 실행축 | 사이징·분할·손절·트레이드플랜·가상매매 데스크 — **가장 완성** | 거의 없음 | 코드 (심법의 수치화) |
| 복기축 | 설계만 (회고 PROPOSAL 원안) | **전부 — 최대 공백** | 채점=코드 / 교훈·제안=LLM+승인 |

## 6. 실행 사다리 — 순서와 기대 효과

| 단계 | 내용 | 기대 효과 | 상태 |
|---|---|---|---|
| **P0** | 채팅 임원 배선 (config 스위치) | 채팅이 어드바이저처럼 말함 — 즉시 체감 | ✅ 오늘 완료 (1430 passed, 서버 재시작만) |
| **P1** | 지식 반입 동적화 — 자료 드롭→LLM 정제→**승인 화면**→canon 반영. 첫 손님 = 보유 6종(신고가·가격수급 신규 + 프랙탈/로그 정제) | "자료 배선 매번 논의" 비용 소멸 + V2/V3 프레임 충전 + Tier 2 설계 재료 준비 | 다음 |
| **P2** | 채점 루프 (=BRAIN Tier 4 / EVOLUTION 합류) | track record 확보 = "확신 없음"의 근본 해소 + 이후 모든 판단의 적합도 함수 | P1 뒤 |
| **P3** | 깔때기 재배선 — ⓐ탑다운(섹터→종목)+장세 슬롯+게이트 닫히면 하위 스킵(비용↓, 앞당김 가능) ⓑ생존자 심층 리포트(YAML→임원식) + 페르소나 정리 합본 | 비용 구조적 해소 + wait 단일음 대신 "오늘은 시장 단계에서 멈춤, 이유는 ○○" + 프리즘급 리포트 | P2 뒤 |
| **P4** | 렌즈 레지스트리 (판단 구조의 선언 데이터화) | 구조 변경이 코드 수정 → 데이터 수정으로 | P3 뒤 |
| **P5** | 동적 통폐합 (채점 근거 PROPOSAL→승인→반영) | 시스템이 스스로 개선안을 제안 — 원안 Layer 5 완성 | P4 뒤 |

**다른 세션(BRAIN 로드맵)과의 정합**: 관측→M2→Tier 2 순서는 그대로. 이 문서의 채점(P2)=그쪽 Tier 4, 사이클 게이지·PANIC-REVERSAL=그쪽 Tier 2. 겹치는 것 없이 좌표계만 통일. 관측 시 주의 1개 — 뉴스 해석 콜이 지금 **사고 기능 꺼짐(thinking=0)+작은 모델**이라, 해석 퀄이 약해 보이면 설계 탓 전에 설정부터 올려볼 것.

## 7. 오늘 감사에서 나온 자잘한 수리 대상 (잊지 않기용)

| 항목 | 내용 |
|---|---|
| 스테일 프롬프트 | 채팅용 뉴스큐레이터 지시문이 "뉴스 인프라 미구현"이라고 거짓 선언 중 (완료된 지 오래) |
| 죽은 배선 | track_selector 미사용 / tier 선언 2곳 미소비 / Gemini 운영인데 Anthropic 캐싱 장치 / crosscheck 설정 |
| 코드 중복 | run_analyst·run_strategist 의 stream 버전 ~150줄 복제 (stream 쪽엔 슬롯 2개 누락) |
| 관측 체크 3건 | 장전 시나리오 파트 2회 연속 빈 출력 / 브리핑·요약 이중 발송 / 밴드 스킵이 "관망 0"으로 보이는 집계 착시 |
| 채팅 이력 미저장 | 대화 연속성 0 (매 질문 콜드스타트) — P3b 즈음 함께 |
| 모순 조항 | 매매저널리스트 페르소나가 "가상매매 데이터로 일지 금지" — 가상매매 북극성과 정면 충돌 |
