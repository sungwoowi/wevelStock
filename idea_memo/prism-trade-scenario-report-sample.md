## 차용 설계 포인트 (요약)
- **다단 지지/저항(1·2차)** — 단일 목표/손절 아님 = "후보 메뉴" 원칙 확증(결정론 스윙 다단).
- **목표가 도달 = 마일스톤, 자동매도 아님** → regime 조건부(parabolic/bull = 즉시매도 금지·trailing 전환·보유 / sideways/bear = 도달 즉시 전량). = "목표 동적"(판단).
- **추세 약화 = multi-condition AND** — 종가 ①20일선 이탈 ②거래량 동반 ③섹터/시장 약세 中 2+ 동시.
- **하드 스탑 = 종가 기준** (장중 wick 일시 이탈은 매도 사유 X) + **오닐 −7% 절대**.
- **시간 점검 = 트리거 아님** (보유 N일 = 추세 점검 시점일 뿐).
- **트리거별 과거 승률** (예 50%·18건) → 적중률(GUIDANCE-ACCURACY·북극성) 연결.
- **보유 지속 조건** 명시 + **매매일지 반영**(과거 경험) + 투자근거(cited 점수·regime·R/R).
- **포트폴리오 관점**: 슬롯 N/10·섹터 분포·승률·누적수익률.
