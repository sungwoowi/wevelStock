## 1. Executive Summary

  

### 🎯 핵심 결정 사항

  

1. **궁극 목표 = 자산 복리 구조**: 시스템의 존재 이유는 **자산 복리 구조 보장**이며, 가이던스 적중도와 수익률은 이를 달성하기 위한 도구

2. **이원 트랙 = 본질적으로 다른 게임**:

   - **Track A (중장기 자산 불리기)** = 큰 자본 + 부동산식 **수익금 게임** (절대 금액, 안정성)

   - **Track B (단기 스윙 현금 인출기)** = 적은 자본 + 트레이딩식 **손익비 수익률 게임** (회전율, 월 현금흐름)

3. **페르소나 통합**: 현 13개 역할 모듈 + prism 차용 3개 = **16명 페르소나**

4. **트랙별 KPI 차별화**: Track A는 수익금·승률·보유기간 / Track B는 손익비·월수익률·회전율

5. **LLM 모델 전략**: Track별 모델 분리 — Track A는 Sonnet/Opus, Track B는 Haiku 빈번 호출

6. **결정론 보존**: 채점 공식은 결정론 유지, LLM 자유채점 금지

  

### 💡 핵심 통찰 (대화에서 추출)

  

- **로그 함수 발산 구간(α 1.3~1.7)이 가장 큰 수익 자리** — 일봉 이격도로 차단하면 안 됨 (사용자 지적)

- **사용자 W계좌 운용 결과(+59%, +110%)가 wevelstock 룰과 일치** — 직관과 시스템이 같은 곳을 향함

- **사용자는 prism형 인간이 아닌 wevelstock형 인간** — 인과 추적 가능성을 중시

- **prism +244%지만 승률 45%** — wevelstock은 +100~150% / 승률 65~75% 추정

- **궁극 목표는 자산 복리 구조** — 적중도·수익률은 도구일 뿐, 시스템은 정직한 나침반

## 1.5 시스템 철학 — 자산 복리 구조와 두 트랙의 본질 ⭐

  

### 1.5.1 목표 위계

  

```

┌─────────────────────────────────────────┐

│        궁극 목표                          │

│   자산 복리 구조 보장                       │

│   (Wealth Compounding Architecture)     │

└────────────────┬────────────────────────┘

                 │ ← 일관된 수익률로 달성

                 ▼

┌─────────────────────────────────────────┐

│        중간 수단                          │

│   안정적·일관된 수익률                      │

│   (Consistent Returns)                  │

└────────────────┬────────────────────────┘

                 │ ← 적중도로 보장

                 ▼

┌─────────────────────────────────────────┐

│        하부 수단                          │

│   가이던스 적중도                          │

│   (Guidance Accuracy)                   │

└────────────────┬────────────────────────┘

                 │ ← 메커니즘으로 구현

                 ▼

┌─────────────────────────────────────────┐

│        작동 메커니즘                       │

│   페르소나·룰·신뢰도·자가진단                │

└─────────────────────────────────────────┘

```

  

→ **시스템 = 자산 복리 구조를 위한 도구.** 적중도는 도구 중 도구. 적중도만 높고 수익률로 전환 안 되면 시스템은 무의미. 수익률 높아도 복리 구조 깨지면 (한 번의 큰 손실로) 모래성.

  

### 1.5.2 두 트랙의 본질적 다름 — 게임 자체가 다르다

  

**Track A (중장기 자산 불리기) ≠ Track B (단기 스윙 현금 인출기)**

  

두 트랙은 같은 시스템 안에서 운영되지만, **본질적으로 다른 게임**을 한다:

  

| 본질 차원 | Track A (중장기) | Track B (단기 스윙) |

|---|---|---|

| **게임 종류** | **수익금 게임** (Absolute Cash Game) | **손익비 게임** (Risk/Reward Game) |

| **자본 성격** | 큰 자본 (자산의 70~80%) | 작은 자본 (자산의 20~30%) |

| **비유** | 🏢 **부동산 임대업** | ☕ **카페 운영** |

| **수익 원천** | 자산 가격 상승 + 시간 가치 | 회전율 × 손익비 |

| **승률** | 70%+ (높은 확률 우선) | 50%+ (낮아도 R/R로 보상) |

| **회전율** | 낮음 (연 5~15회) | 높음 (월 5~15회) |

| **개별 거래 의미** | 큰 자본의 안정적 운용 | 월간 현금흐름 발생 |

| **실패 시 영향** | 자산 베이스 타격 (큰일) | 그달 인컴 손실 (회복 가능) |

| **목적의식** | "자산 불리기" — 부의 축적 | "제2의 소득" — 월 인컴 확보 |

| **부동산 비유** | 빌딩 매입 후 임대 | 단기 부동산 갭투자 회전 |

  

### 1.5.3 왜 같은 KPI로 두 트랙을 평가하면 안 되는가

  

같은 KPI 적용 시 본질 왜곡 사례:

  

❌ **Track A에 "수익률"을 들이대면**: 부동산 임대업자에게 "이 빌딩 매월 몇 % 올랐냐"고 묻는 격. **잘못된 질문**.

- 올바른 질문: "월 임대 수익이 얼마인가?" "공실률은?" "임차인 안정성은?"

  

❌ **Track B에 "절대 수익금"을 들이대면**: 카페 사장에게 "이번 달 자산이 얼마 늘었냐"고 묻는 격. **잘못된 질문**.

- 올바른 질문: "이번 달 매출 회전이 어땠나?" "객단가 × 회전율 = 월수익률은?"

  

✅ **올바른 트랙별 평가**:

  

**Track A KPI 우선순위**:

1. 절대 수익금 (Absolute Profit)

2. 승률 (Hit Rate)

3. 평균 보유 기간 (Holding Duration)

4. MDD (Max Drawdown) — 복리 구조 보호 핵심

5. 자산 베이스 증가율 (Asset Base Growth)

  

**Track B KPI 우선순위**:

1. 손익비 실현율 (R/R Realization)

2. 월간 수익률 (Monthly Return Rate)

3. 회전율 (Trade Frequency)

4. 평균 수익/trade

5. 월 인컴 안정성 (Income Consistency)

  

### 1.5.4 자산 복리 구조 보장의 의미

  

복리(compound)는 **연속성**이 핵심이다. 한 번의 -50%는 두 번의 +50%로도 복구 안 됨 (1 → 0.5 → 0.75, 아직 -25%).

  

→ **두 트랙 모두 "복리 구조를 깨지 않는 것"이 절대 룰**:

- Track A: MDD 관리 (월봉 7월선 위계 = 복리 구조 보호 장치)

- Track B: 손절 절대 룰 (-7% 절대 매도 = 한 거래가 인컴 흐름 끊지 못하게)

  

복리 구조 우선 = **큰 손실 한 번을 피하는 것이 작은 수익 열 번보다 중요**.

### 3.2 두 트랙의 분리 원칙

  

> **본질 재확인** (Section 1.5.2 참조): Track A는 **수익금 게임**(부동산 임대업), Track B는 **손익비 게임**(카페 운영). 자본 성격·게임 룰·평가 기준이 다르다.

  

| 구분           | Track A (중장기 위계)            | Track B (단기 스윙)                |
| ------------ | --------------------------- | ------------------------------ |
| **본질 게임**    | 🏢 수익금 게임 (절대 금액)           | ☕ 손익비 게임 (R/R)                 |
| **자본 비중**    | 자산의 70~80% (본진)             | 자산의 20~30% (인컴)                |
| **시간 지평**    | 3~12개월                      | 1주~3개월                         |
| **시간축 위계**   | 월봉 7선 > 주봉 MFI > 일봉 Vol Osc | 일봉 단일 + 시간외 시그널                |
| **거인 페르소나**  | 와인스타인 + 엘더 + 엘리어트 + 미너비니    | 오닐 (CAN SLIM 단독)               |
| **진입 조건**    | 월봉 7선 위 + α≥1.3 발산 OR 눌림목   | 트리거 발동 + buy_score ≥ min_score |
| **포지션 비중**   | 종목당 20~40% (집중)             | 종목당 5~15% (분산)                 |
| **최대 슬롯**    | 3~5종목                       | 5~10종목                         |
| **손절 정책**    | 월봉 7선 종가 이탈                 | 시장 체제별 -5%~-7%                 |
| **익절 정책**    | Module A 목표가 3단 + trailing  | trailing stop (활성화 후)          |
| **거래 빈도 목표** | 월 1~3회 (낮은 회전)              | 월 5~15회 (높은 회전)                |
| **목표 승률**    | 70%+                        | 50%+                           |
| **목표 R/R**   | 평균 3:1                      | 평균 1.5:1                       |

### 📊 Tier 2 — Track A 본진 (중장기 위계, 5명)

  

#### #4. 주도주 Identifier (월봉 7월선 위계 판정관)

- **거인**: 알렉산더 엘더 (Triple Screen) + 미너비니 (SEPA 4단계)

- **역할**: 월봉 7/9/36/60선 정배열 + 월봉 종가 7월선 위 + 7월선 상향 → **정배열_점수**

- **핵심 룰**: "월봉 7월선 위계 최우선" — 일봉·트레이딩 시각으로 위계 부정 금지

- **출력**: 정배열_점수 (1~10점) + 단계 라벨 (Stage 1/2/3/4)

  

#### #5. Wave Mathematician (Module A 로그 파동 엔진) ⭐ 핵심

- **거인**: 랄프 엘리어트 + 로버트 프렉터

- **역할**: A/B/C 앵커 → 로그 기울기 → 가속계수 α → 목표가 3단

- **공식**:

  ```

  R₁ = B/A

  R₂ = 현재가/C

  k₁ = ln(B/A) / 기간₁

  k₂ = ln(현재가/C) / 기간₂

  α = k₂ / k₁

  목표가 1 = C × R₁

  목표가 2 = C × R₂ × 기간투영

  목표가 3 = 목표가 2 × min(1.5~2.0×α, 보정상한)

  ```

- **⭐ α 기반 T-Score 오버라이드 룰 (v3.0 핵심 패치)**:

  | α 범위 | T-Score 이격도 강제 보정 | 매매 의미 |

  |---|---|---|

  | α < 0.8 | 기본 룰 유지 | 둔화, 관망 |

  | 0.8 ≤ α < 1.3 | 기본 룰 유지 | 정상 추세 |

  | 1.3 ≤ α < 1.5 | max(원래값, 5) | 발산 시작, 분할진입 |

  | 1.5 ≤ α < 2.0 | max(원래값, 7) | 강발산, 적극 진입 ⭐ |

  | α ≥ 2.0 | min(원래값, 3) | 폭주, 부분 청산 |

  

#### #6. Survival Inspector (Module B 생존 필터)

- **거인**: 반 K. 타프 (Position Sizing) + 와인스타인

- **역할**: F1~F5 Boolean 체크

  - F1: 월봉 종가가 7월선 위

  - F2: 최근 조정저점이 7월선 부근 V반등

  - F3: 7월선 기울기 상승 중

  - F4: 직전 파동 대비 확장비 유지/증가

  - F5: 일봉 MACD 히스토그램 마디 살아있음

- **핵심 룰**: F1~F3 중 1개라도 False → Module A 목표가 무효 → 청산 모드

  

#### #7. S-Score Auditor (셋업 품질 채점관)

- **공식**: `S = RS×0.4 + 공급망×0.3 + 정배열×0.3` (10점 만점)

- **결정론적**: 재현성 ±0.5점 이내

  

#### #8. T-Score Auditor (진입 타이밍 채점관)

- **공식**: `T = 이격도×0.3 + MACD×0.3 + 거래량×0.2 + 손익비×0.2` (10점 만점)

- **⭐ α 오버라이드 적용 후 최종 T-Score 산출**

## 6. 가이던스 적중도 측정 프레임워크 ⭐

  

> **목적의 재확인**: 가이던스 적중도는 **수익률 일관성을 위한 도구**이며, 수익률은 **자산 복리 구조 보장을 위한 도구**다. 적중도 측정은 목적이 아니라 시스템 진화의 피드백 루프다.

>

> **트랙별 KPI 차별 적용** (Section 1.5.3 참조): Track A는 수익금·승률 우선 / Track B는 손익비·회전율 우선. 같은 지표를 두 트랙에 동일 가중치로 적용하지 않는다.

  

### 6.1 5대 적중도 지표 (트랙별 가중치 차별 적용)

  

#### 📈 KPI #1. 방향 적중률 (Direction Hit Rate)

- **정의**: 권고 후 N일 내 예측 방향 도달 비율

- **측정**:

  ```

  N=30일 기준:

  - 매수 권고 후 +5% 이상 도달 → Hit

  - 매도 권고 후 -5% 이상 하락 → Hit

  - 대기 권고 후 박스 유지 → Hit

  ```

- **목표**:

  - Track A: **70%+** (수익금 게임의 핵심 — 큰 자본은 자주 틀리면 안 됨)

  - Track B: **55%+** (손익비 게임 — 낮은 승률도 R/R로 보상 가능)

- **트랙별 가중치**: Track A 30% / Track B 15%

  

#### 🎯 KPI #2. 타점 정밀도 (Entry Precision)

- **정의**: 권고 진입가 vs 실제 30일 내 저점 차이

- **측정**:

  ```

  타점_오차율 = (권고진입가 - 실제30일저점) / 실제30일저점 × 100%

  ±3% 이내 → A급 (저점에 가까운 진입)

  ±5% 이내 → B급

  ±10% 이내 → C급

  10%+ → D급 (피해야 할 진입)

  ```

- **목표**: A+B급 합계 60%+

- **트랙별 가중치**: Track A 15% / Track B 20% (단기는 타점이 곧 손익비)

  

#### 💎 KPI #3. 손익비 실현율 (R/R Realization)

- **정의**: 권고 R/R 대비 실제 실현 R/R

- **측정**:

  ```

  실현_R_R = (실제최고가 - 진입가) / (진입가 - stop_loss)

  실현율 = 실현_R_R / 권고_R_R × 100%

  ```

- **목표**:

  - 50% 이상 → 시스템 신뢰 가능

  - 80% 이상 → 시스템 우월

  - 30% 미만 → 시스템 재검토 필요

- **트랙별 가중치**: Track A 15% / Track B 35% (손익비 게임의 핵심)

  

#### 🔍 KPI #4. 자가 진단 정확도 (Self-Diagnosis Accuracy)

- **정의**: 시스템이 🔴 라벨링한 부분이 실제로 틀린 비율

- **측정**:

  ```

  진단_정확도 = (🔴 라벨 중 실제 부정확했던 항목 수) / (총 🔴 라벨 수) × 100%

  ```

- **목표**:

  - 70%+ → 메타 인지 정상 작동

  - 30% 미만 → 라벨링 무의미 (과도한 보수)

- **트랙별 가중치**: Track A 15% / Track B 15% (양 트랙 공통 중요)

  

#### 🏆 KPI #5. 트랙 분리 효과 (Track Separation Effect)

- **정의**: Track A vs Track B 권고의 게임 본질에 맞는 성과 분리

- **측정 (트랙별 다른 지표)**:

  | 지표 | Track A 목표 (수익금 게임) | Track B 목표 (손익비 게임) |

  |---|---|---|

  | **1순위 KPI** | **절대 수익금** (KRW 누적) | **손익비 실현율** (%) |

  | **2순위 KPI** | 승률 70%+ | 월 회전율 5~15회 |

  | **3순위 KPI** | 평균 보유 60일+ | 평균 보유 7~14일 |

  | **4순위 KPI** | MDD -8% 이하 (복리 보호) | 손절 절대룰 준수율 100% |

  | **5순위 KPI** | 자산 베이스 증가율 | 월 인컴 안정성 (변동계수) |

- **트랙별 가중치**: Track A 25% / Track B 15%

- **실패 시그널**: Track A는 수익금 ↑인데 MDD ↑↑ / Track B는 회전율 ↑인데 R/R 실현 ↓

  

### 6.1.1 트랙별 가중치 정리

  

```

Track A 종합 점수 = 방향적중률×0.30 + 타점정밀도×0.15

                  + R/R실현×0.15 + 자가진단×0.15

                  + 트랙분리×0.25

   → 강조: 방향적중률 + MDD (복리 구조 보호)

  

Track B 종합 점수 = 방향적중률×0.15 + 타점정밀도×0.20

                  + R/R실현×0.35 + 자가진단×0.15

                  + 트랙분리×0.15

   → 강조: 손익비 실현 + 타점 정밀도 (월 인컴 안정성)

```

### 6.3 적중도 → 수익률 → 자산 복리의 위계

  

> ⚠️ **중요 정정**: 적중도와 수익률은 도구이며, 궁극 목표는 자산 복리 구조다.

  

**위계 재확인**:

```

자산 복리 구조 ← (최종 목표)

   ↑ 안정적 일관성으로 달성

일관된 수익률 ← (중간 수단)

   ↑ 적중도가 수익률 일관성을 보장

가이던스 적중도 ← (하부 수단)

   ↑ 시스템 룰·페르소나·메타인지로 구현

시스템 메커니즘

```

  

**prism-insight의 +244.63% 누적 수익률 사례**:

- 승률 45% (적중률 ≈ 45%) — 55%의 권고가 빗나감

- 한 번 맞은 큰 수익이 9번 손실을 메꿈

- 결과: **누적 수익률은 높지만 일관성·재현성·복리 구조 보장은 약함**

  

**wevelstock v3.0의 차별화**:

  

| 평가축             | prism            | wevelstock v3.0                 |
| --------------- | ---------------- | ------------------------------- |
| 누적 수익률          | 단기 폭발 (244%)     | 점진 누적 (100~150% 추정)             |
| 적중률             | 45%              | 70%+ (Track A) / 55%+ (Track B) |
| 일관성             | 낮음 (변동성 큼)       | 높음 (시간축 위계 보호)                  |
| 복리 구조           | 큰 손실 한 번에 위험     | MDD -8% 이하로 보호                  |
| **장기 5년 시뮬레이션** | 폭락장 한 번에 자산 -40% | 연 15~20% 안정 복리                  |

  

**자산 복리 5년 시뮬레이션 (1억 시드 기준)**:

  

| 시나리오                 | 연 수익률                 | 5년 후      | MDD 한 번             | 실질 결과               |
| -------------------- | --------------------- | --------- | ------------------- | ------------------- |
| prism형 (높은 수익+큰 손실)  | 평균 +35%, 단 1년 -30% 발생 | 1억 → 2.6억 | 자산 -30% (1년차에 발생 시) | **현금화 압박, 복리 깨짐**   |
| wevelstock형 (꾸준한 수익) | 평균 +18%, MDD -8%      | 1억 → 2.3억 | 견딜만 함               | **복리 구조 유지, 심리 안정** |

  

→ **5년 후 총액은 비슷하지만, 복리 경로의 안정성·심리적 지속가능성에서 wevelstock 우월**.

  

→ **사용자가 추구하는 것은 단발 +244%가 아니라 매년 +15~20% × 10년 = 4~6배 자산**. 이것이 자산 복리의 진짜 의미.

## 8. 부록 — 시스템 프롬프트 패치 v2.7 → v3.0

  

### 8.1 v2.7 패치 (α 오버라이드 룰)

  

기존 v2.6-lite의 4번 섹션(결정론적 채점 공식)에 다음 추가:

  

```markdown

## 4.5 가속계수 α 기반 T-Score 오버라이드 ⭐ v2.7 NEW

  

사용자가 엑셀로 입력한 A/B/C 앵커값으로 α가 계산된 경우:

  

| α 범위 | T-Score 이격도 강제 보정 | 매매 의미 |

|---|---|---|

| α < 0.8 | 기본 룰 유지 | 둔화, 관망 |

| 0.8 ≤ α < 1.3 | 기본 룰 유지 | 정상 추세 |

| 1.3 ≤ α < 1.5 | max(원래값, 5) | 발산 시작, 분할진입 |

| 1.5 ≤ α < 2.0 | max(원래값, 7) | 강발산, 적극 진입 |

| α ≥ 2.0 | min(원래값, 3) | 폭주, 부분 청산 신호 |

  

→ 사용자 시스템의 본질은 "발산 구간 참여"이며,

   일봉 이격도는 비중 결정 신호일 뿐 참여 차단 신호가 아니다.

   월봉 α는 "참여 여부"를 결정하고, 일봉 이격은 "비중 크기"를 조정한다.

  

### S-T Matrix 패치 (α 보정 반영)

## 🎯 마무리 — 가장 중요한 한 줄

  

> **시스템의 존재 이유는 "자산 복리 구조 보장"이다.**

>

> 가이던스 적중도는 도구이고, 수익률은 그 도구가 만드는 결과이며, 자산 복리 구조는 그 결과의 누적이다.

> 시스템 = 자산 복리 구조를 위한 도구 → 그 안의 적중도는 도구를 위한 도구.

>

> **두 트랙이 본질적으로 다른 게임**임을 잊지 마라:

> - **Track A 중장기** = 🏢 부동산 임대업식 **수익금 게임** (큰 자본, 안정, 자산 불리기)

> - **Track B 단기 스윙** = ☕ 카페 운영식 **손익비 게임** (작은 자본, 회전, 월 인컴)

>

> 같은 KPI로 두 트랙을 평가하면 본질이 흐려진다.

> Track A는 절대 수익금과 MDD로 평가하고, Track B는 손익비 실현율과 회전율로 평가한다.

>

> 시스템이 부를 만드는 게 아니라, **사용자가 시스템 위에서 부를 만든다.**

> 시스템은 자산 복리 구조를 깨지 않게 보호하는 정직한 나침반이다.

> 단발 +244%가 아니라, **매년 +15~20% × 10년 = 4~6배 자산**이 진짜 목표다.
