# 주식 어드바이저 — 에이전트 협업 시스템

## 프로젝트 개요
멀티팀 AI 주식 분석 & 매매가이드 시스템.
각 팀이 독립 분석 → 오케스트레이터가 종합 → 최종 투자 가이드 생성.
크로스 플랫폼(Mac + Windows). DB: SQLite. API: 한국투자증권(KIS) OpenAPI.

## 프로젝트 구조
```
teams/           — 팀별 독립 모듈. 다른 팀의 코드를 절대 import하지 않는다.
  {팀명}/
    CLAUDE.md    — 팀 컨텍스트 (이 팀 폴더에서 작업 전 반드시 읽을 것)
    persona.md   — 팀 페르소나 & 전문성 정의
    src/         — 구현 코드
    tests/       — 테스트
mcp-servers/     — 외부 데이터 연동 (KIS API, FRED, 알림)
webapp/          — Next.js 웹앱 (PC + 모바일 반응형)
data/db/         — SQLite 데이터베이스 (공유. 팀들은 표준 스키마로 쓰기)
knowledge/       — 학습 자료 (파동이론, 매크로 경제학 등)
docs/            — 설계 문서 & 스펙 (사람용 참조 문서. 실행용 아님)
  specs/         — 기능 명세서 (SPEC-XXX.md). 구현 전 반드시 해당 스펙 읽을 것.
scripts/         — 유틸리티 (스케줄러, 백업, 갭필링)
```

## 팀 간 통신 계약
모든 팀은 동일한 JSON 형태로 출력한다. 오케스트레이터만 이것을 읽는다.
```json
{
  "team_id": "macro-analysis",
  "timestamp": "2026-04-14T09:00:00+09:00",
  "verdict": "상승장",
  "confidence": 78,
  "reasons": ["금리 안정", "유동성 증가", "VIX 하락"],
  "data": { /* 팀별 고유 데이터 */ }
}
```
팀끼리 서로 import 금지. 공유 DB 테이블만 읽는다.

## 코딩 규칙
- 파이썬: pathlib 전용 (문자열 경로 조합 금지). 모든 함수에 타입 힌트.
- 크로스 플랫폼: .sh 스크립트 금지. 파이썬 스크립트 또는 justfile 사용.
- DB: SQLite, ON CONFLICT REPLACE (멱등성 보장).
- 환경변수: 모든 시크릿은 .env에. 하드코딩 절대 금지. python-dotenv로 로드.
- 테스트: pytest. 각 팀 tests/ 폴더에 작성.
- Git: feature 브랜치에서만 작업. main 직접 커밋 금지.
  커밋 메시지: [팀명] 설명 (예: [macro] 금리 역전 감지 추가)
- 의존성: 파이썬은 uv, 노드는 pnpm.

## KIS API 안전 규칙
- 주문 관련 코드 작성 시 반드시 KIS_IS_PAPER=true 확인.
- OAuth 토큰은 메모리에만 보관. 파일 저장 절대 금지. 만료 전 자동 갱신.
- API 호출 간격: 최소 100ms. 초당 최대 20건.

## 투자 7계명 (불변)
1. 총 투자비중 80% 이하 유지
2. 단일 종목 비중 15% 이하
3. 트레이딩 비중 20% 이하
4. 손절선 없이 진입하지 않음
5. 단일 지표로 판단하지 않음 (최소 3개 교차 검증)
6. 데이터 없이 추측하지 않음
7. 감정(FOMO/공포)으로 매매하지 않음

## 기능 구현 절차
1. docs/specs/ 에서 해당 SPEC 파일을 먼저 읽는다.
2. 대상 팀의 CLAUDE.md와 persona.md를 읽는다.
3. 해당 팀의 src/ 폴더 안에서만 구현한다.
4. 테스트를 작성한다.
5. 기존 테스트가 여전히 통과하는지 확인한다 (회귀 방지).
6. 동작이 바뀌었으면 팀의 CLAUDE.md를 업데이트한다.
7. docs/changelog.md에 변경 이력을 추가한다.

## 전략 라우팅 (병렬 운용)
- 단타 트레이딩: 기술적분석팀 + 수급팀 → 당일 시그널
- 스윙 트레이딩: 기술적분석팀 + 수급팀 + 매크로팀 → 수일~수주 포지션
- 자산 투자: 매크로팀 + 기술적분석팀 + 원칙팀 → 장기 보유
각 전략은 독립 실행. 오케스트레이터가 최종 병합.
