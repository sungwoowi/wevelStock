## 🌅 아침 한 줄 요약

**Track A(중장기 주도주, 3~6달 보유)는 실제로 시장을 이긴다 — 검증된 본진을 찾았다.**
"이평선 정배열 + 상대강도"로 고른 상위 종목을 분기마다 교체하면, 단순히 전체를 사서
들고 있는 것보다 **연복리 +8.7%p 더 벌고, 하락장에선 거의 2배, 게다가 낙폭(손실)도 더 작다.**
단 **절대 수익률 숫자는 생존편향으로 뻥튀기**돼 있으니 *상대 우위*만 믿어야 한다.
**Track B(단기)는 아직 미검증** — 단기 추격은 하락장에 안 통하고, 박스권 매매에 희미한
씨앗만 있다. 360분봉 데이터가 없어 한계.

## 📖 용어 사전 (모르는 말 전부 풀이)

| 용어 | 쉬운 뜻 |
|---|---|
| **신호(signal)** | 종목을 줄 세우는 기준 점수. "이 종목 좋아 보이는 정도." |
| **상대강도(모멘텀, mom)** | 최근 몇 달간 많이 오른 정도. "잘 달리던 말이 더 달린다"는 발상. |
| **이평선(MA, 이동평균선)** | 최근 N일 종가 평균을 이은 선. 주가가 그 위에 있으면 상승 분위기. |
| **정배열(ma_stack)** | 짧은 이평선이 긴 이평선보다 위에 차곡차곡 쌓인 상태(종가>20일>60일>120일). 강한 상승 구조. |
| **α(알파)** | 당신 고유의 프랙탈+로그 파동 점수. 주가 사이클의 어느 위치·가속 정도인가. |
| **가속도(2차함수 진입)** | 상승 추세가 *점점 빨라지는* 구간. 직선이 아니라 위로 휘는(볼록) 구간 진입. |
| **지평선(horizon)** | "사서 며칠/몇 달 들고 있나." 2주 / 1달 / 3달 / 6달. |
| **분위(quintile)** | 줄 세워 5등분. **Q5**=최상위 20%, **Q1**=최하위 20%. |
| **edge(엣지)** | "상위 20%(Q5)의 수익 − 전체 평균 수익." *상위가 평균보다 얼마나 더 버는가* = 선택 실력. |
| **IC (정보계수, Information Coefficient)** | **신호 순위와 실제 수익 순위가 얼마나 일치하나(−1~+1).** +1=점수 높을수록 더 오름(완벽), 0=무관(찍기), −=거꾸로. 보통 +0.03만 넘어도 의미있다고 본다. *우리 결과는 대부분 0 근처라, "전 종목이 깔끔히 비례"하진 않고 "최상위만 잘 됐다"는 뜻.* |
| **장세(regime)** | 시장 상황. 상승장 / 하락·횡보장. 우리는 2022~2024를 하락·횡보로 봄. |
| **평균회귀(mean reversion)** | "너무 빠지면 되돌아 오른다"는 발상. 박스권 저점 매수가 이 원리. |
| **cutoff(컷오프)** | "이 날짜 이후는 안 본다"는 컨닝 방지 칸막이(미래 정보 차단). |
| **백테스트(backtest)** | 과거로 돌아가 "그때 이 전략 썼으면 어땠나"를 시뮬레이션. 몇 달 안 기다리고 검증. |
| **누적수익 / CAGR** | 누적 = 전체 기간 총 몇 % 불었나. CAGR = 그걸 *연복리 평균*으로 환산(연 몇 %씩). |
| **변동성(volatility)** | 수익이 출렁이는 폭. 클수록 마음 졸임. |
| **샤프(Sharpe)** | 수익 ÷ 변동성 ≈ "마음 졸인 만큼 잘 벌었나"(효율). 높을수록 좋음. 1 넘으면 양호. |
| **MDD(최대낙폭)** | 고점 대비 가장 크게 빠졌던 폭. −30%면 자산이 한때 30% 줄었다는 것. 작을수록 좋음. |
| **거래비용** | 사고팔 때 수수료+세금(한국 매도세 등). 자주 사고팔수록 수익을 갉아먹음. |
| **교체율(turnover)** | 한 번 교체할 때 포트폴리오의 몇 %를 갈아치우나. 높을수록 비용↑. |
| **생존편향(survivorship bias)** | *지금 살아남은 종목만* 보면 결과가 좋게 나오는 착시(망해서 사라진 종목은 목록에 없음). **이번 절대 수익률이 비현실적으로 높은 주범.** |
| **벤치마크(benchmark)** | 비교 기준. 우리는 "전체 167종목을 똑같이 나눠 사서 들고 있기"(=종목 선택 0)를 시장으로 삼음. |

## 🔬 무엇을, 어떻게 실험했나

- **종목**: 우리 DB에 일봉(하루 종가)이 충분히(500거래일+) 쌓인 **한국 주식 167개**.
- **기간**: **2018-12 ~ 2026-06** (약 7년 반), 매일 종가.
- **데이터**: 주가만 사용. (뉴스·재무제표는 과거가 얕아 신뢰 불가라 제외.)
- **방법**: 과거 여러 시점으로 "타임머신"을 보내, 그 시점까지의 정보만으로 종목을 신호로
  줄 세우고 → 일정 기간 뒤 실제 수익으로 채점. 미래 정보는 차단(cutoff).
- **두 가지 측정**: ① **edge**(상위 20%가 전체 평균을 이긴 폭) ② **IC**(순위 일치도).
  그리고 ③ **전략 백테스트**(실제로 사서 보유·교체·비용 차감한 자산곡선).

## 🧮 테스트 알고리즘 로직 (정확히 어떻게 계산했나 — 신뢰도용)

스크립트가 *블랙박스가 아님*을 위해, 실제 계산 단계를 그대로 풀어 적는다.
(원본: `scripts/_backtest_trackA_strategy.py` 외 `_backtest_*.py`.)

### ① 데이터 적재
- `chart_ohlcv`에서 (종목, 날짜, 종가)만 읽음 → 종목별 날짜순 정렬.
- **500봉 미만 종목 제외** → 167종 확정. 종가 외(거래량·재무 등)는 안 씀.

### ② 신호 계산 — *각 종목, 각 날짜, 그 날까지의 데이터로만*
- MA20 / MA60 / MA120 = 최근 20 / 60 / 120일 종가 평균(이동평균선).
- **정배열 `ma_stack`** = (종가>MA20) + (MA20>MA60) + (MA60>MA120) → **0~3점**.
- **상대강도 `mom_120`** = 종가 ÷ (120일 전 종가) − 1.  (= 최근 6개월 수익률)
- 두 값 모두 *과거* 종가만으로 계산 → 미래를 절대 안 봄(컷오프 보장).

### ③ 시점·종목 선택 (Track A 전략 백테스트)
- 시작 = 121번째 거래일부터(MA120 확보된 시점). **리밸런스 = 20 / 60 / 120 거래일마다**(월/분기/반기).
- 각 리밸 날짜 `t`에서: ⓐ 그 날 신호가 유효하고 ⓑ `t`와 *다음 리밸* `t2` 양쪽에 종가가 있는
  종목만 **후보**로 삼음.
- **점수** = (후보들 사이) `ma_stack`의 백분위순위 + `mom_120`의 백분위순위. → **상위 20% 선택, 동일가중.**

### ④ 수익·비용·자산곡선
- **보유수익** = 선택 종목들의 `(t2종가 ÷ t종가 − 1)` 평균. (= `t`에 사서 `t2`까지 들고 있었을 때 수익)
- **교체율** = 1 − (직전 보유와 겹치는 종목 비율). **비용** = 교체율 × 0.30%(왕복 근사). 비싸게 자주 갈수록 깎임.
- **자산** = 자산 × (1 + 보유수익 − 비용). 매 리밸 반복 → 자산곡선.
- **벤치마크(시장)** = 같은 날 *전체 후보*를 동일가중 보유한 수익(= 종목선택 0). 전략이 이걸 이겨야 "실력".

### ⑤ "미래 안 봄" 보장 (가장 중요)
- 종목 선택은 **`t`까지의 정보만** 사용. 수익은 **`t`→`t2` 실제 보유 구간**(당신이 실제로 먹었을 몫).
- *미래 종가를 보고 종목을 고른 적이 단 한 번도 없다.* (백테스트 신뢰의 핵심 = 이 칸막이.)

### ⑥ 신호 검증 프로브(IC·edge)의 로직
- 각 리밸 날짜에 종목을 신호로 줄세움 → **IC** = spearman(신호 순위, 미래수익 순위),
  **edge** = 상위20%(Q5) 평균수익 − 전체 평균수익. 여러 날짜에 걸쳐 평균.
- 장세분리 = 리밸 날짜가 2022~2024면 하락장, 아니면 상승장으로 나눠 각각 집계.

## 🧬 167종목은 편향됐나? (정직한 진단 — 결과 신뢰의 핵심)

**그렇다, 편향이 있다.** 결과를 믿는 정도를 정하려면 반드시 알아야 한다.

### 167종은 무엇인가 (실측)
- **데이터 시작연도**: 2018년 98종 + 2019년 47종 = **145종(87%)이 7년 내내 존재** = *오래 살아남은 종목*.
- **시장 혼합**: KOSPI/KOSDAQ 섞임. 대형(삼성전자·SK하이닉스·기아·현대차·LG이노텍) +
  중소형(가온전선·대한전선·삼화콘덴서·KBI메탈·동진쎄미켐·대한광통신 등). *초대형주만은 아님.*
- **출처**: 시스템이 차트를 받아온 종목 = 시간이 지나며 **거래대금 상위에 들었거나 워치리스트**에 있던 종목.

### 편향 3가지
1. **생존편향(가장 큼)**: 상장폐지·반토막 후 사라진 종목이 **0개**. → 절대 수익률(+1000%, +47% CAGR)이
   비현실적으로 높은 *주범*. 현실엔 망한 종목도 섞이는데 그게 빠짐.
2. **선택편향(look-ahead 성격)**: "결국 주목받고 유동성 커진" 종목 위주. → 모멘텀·추세 신호가
   *실제 전체 시장에서보다 좋아 보일* 수 있음(승자가 과대표집 → 모멘텀이 승자를 고르는 게 순환적으로 유리).
3. **전체 시장 아님**: 전체 ~2,000여 상장종목 중 **167종 표본**. 소외·저유동 종목 빠짐.

### 그래서 결과를 얼마나 믿나
- ❌ **절대 수익률**(+1000%·+47% CAGR): **거의 안 믿음.** 편향 뻥튀기.
- ⚠️ **상대 우위**(전략이 *같은 167종 동일가중*을 +8.7%p·낮은 MDD로 이김): **부분 신뢰.**
  벤치마크가 *같은 편향 풀*을 공유하므로 **생존편향은 상당 부분 상쇄**된다(둘 다 살아남은 종목만 봄).
  단 **선택편향(승자 과대표집)은 모멘텀 edge를 다소 부풀릴 수 있어** *상한선*으로 봐야 한다.
- ✅ **방향성**("정배열+상대강도 선택이 단순 보유를 이긴다, 특히 하락장에"): **신뢰.** 단 *크기*는
  과장됐을 수 있음 → **상장폐지 포함한 정직한 유니버스로 재검증 필수**(로드맵 B의 핵심 이유).

## 📊 오늘의 발견 종합

### 1) 신호별 선택 실력 (장세·지평선별 edge)

| 트랙 | 신호 | 결론 |
|---|---|---|
| **Track A (3~6달)** | **이평선 정배열 + 상대강도** | 🟢 **검증** — 6달 보유 시 하락장 +4%대, 양 장세 모두 +. |
| Track A | 가속도(2차함수)·신고가 근접 | 🔴 거친 프록시론 약함 → *랭킹 주력 아닌 진입 트리거로*. |
| Track B (2주~1달) | 박스저점(평균회귀) | 🟡 유일하게 IC가 +인 *씨앗*, 단 +0.2%로 미미·2주만. |
| Track B | 추격형(모멘텀·신고가) | 🔴 하락장 0~음수 (단타는 하락장엔 박스권만 — 당신 말대로 정상). |

**핵심**: 단기 1개월 보유로는 어떤 신호도 거의 무의미. **6~12개월으로 갈수록 선택 실력이
드러나고, 그 실력은 하락·횡보장에서 가장 강하다**(비수기에 좋은 종목/잡주가 갈리므로).

### 2) Track A 전략 백테스트 (실제 포트폴리오, 비용 차감, vs 시장)

"이평선 정배열+상대강도 상위 20% 보유, 정기 교체" 전략의 성적:

| 교체 주기 | 전략 CAGR | 시장 CAGR | 초과 | 전략 MDD | 시장 MDD | 하락장(전략/시장) |
|---|---|---|---|---|---|---|
| 월(20일) | +45.3% | +39.8% | +5.5%p | −32.6% | −26.8% | +35% / +27% |
| **분기(60일) ⭐** | **+47.0%** | +38.2% | **+8.7%p** | **−17.5%** | −22.7% | **+61.7% / +34.6%** |
| 반기(120일) | +52.4% | +39.8% | +12.6%p | −29.0% | −18.3% | +66.2% / +30.0% |

**읽는 법**: 전략이 **모든 교체 주기에서 시장을 이긴다**. 특히 **분기 교체(≈당신이 현실적이라
한 3~6달 보유)가 sweet spot** — 시장보다 연 +8.7%p 더 벌면서 **낙폭은 오히려 더 작다**
(−17.5% vs −22.7%). 그리고 **하락장에서 시장의 거의 2배**(+61.7% vs +34.6%). 즉
*선택 실력이 비수기에 빛난다*는 신호별 발견이 실제 포트폴리오에서도 재현됨.

## ⚠️ 반드시 알아야 할 한계 (절대 잊지 말 것)

1. **절대 수익률은 가짜에 가깝다 — 생존편향.** 167종은 *지금 살아남은* 종목이라 망한 종목이
   빠져 있어 +1000% 같은 숫자가 나온다. 현실 아님. **믿을 건 "전략이 시장을 이긴 *상대* 폭"**
   (+8.7%p, 낮은 MDD)이지 절대 숫자가 아니다. 그 상대 폭조차 다소 부풀려졌을 수 있다.
2. **벤치마크가 진짜 코스피가 아니다.** "167종 동일가중 보유"라서, 대형주 가중인 실제
   코스피와 다르다. (선택 실력 *순수* 측정엔 이게 더 맞지만, 절대 비교는 아님.)
3. **거래비용은 근사**(왕복 0.3%), 슬리피지·체결 불가·세금 디테일 미반영.
4. **파라미터 미최적화**지만 동시에 *과최적화 위험*도 있음(단순 신호라 낮은 편).
5. **Track B·360분봉·재무·뉴스 과거 데이터 부재** → 그 영역은 검증 불가.

## 🚀 알파 트레이딩 시스템이 되기 위한 로드맵

오늘 발견을 토대로, 우선순위 순서:

### A. 【지금 바로】 Track A를 검증된 토대 위에 세운다
- 엔진 = **이평선 정배열 + 상대강도 → 상위 종목 → 분기(3~6달) 교체.** 이건 *증명된* 핵심.
- 신고가/가속도는 *진입 트리거*로 보조(랭킹 주력 아님). α의 정밀 파동은 그 위 정밀화 SLOT.
- → 현재 Track A 권고 로직을 이 신호 조합에 명시적으로 정렬.

### B. 【필수 인프라】 백테스트를 "정직"하게 만든다 (BACKTEST SPEC)
- **생존편향 제거**: 상장폐지된 종목까지 포함한 유니버스(point-in-time membership).
- **진짜 비용·슬리피지·실제 KOSPI 벤치마크** 반영.
- 이게 있어야 "+8.7%p"가 진짜인지, 거품인지 판별 가능. → 정식 SPEC으로 격상.

### C. 【시스템의 심장】 "진실의 루프"를 무인으로 돌린다
- 가상매매를 **24/7 무인 가동**(노트북 절전에 안 죽게 = OPS/클라우드) →
  **매일 권고·체결·청산을 벤치마크 대비 정직하게 채점** →
  **회고/진화팀이 결과를 읽고 두뇌의 약점을 진단·교정**. 이 루프가 한 바퀴 = 1세대.
- α의 LLM 주도주 선택은 *백테스트가 불가능*(미래를 앎)하므로, **그 가치는 오직 이
  forward 루프로만** 정직하게 증명된다. → 이게 "스스로 진화하는 두뇌"의 실체.

### D. 【Track B 숙제】 단기 게임은 별도 무기가 필요
- **360분봉 인트라데이 데이터 확보**(현재 없음) — Track B의 핵심 차원.
- **정밀한 박스/레벨 정의 + 타이트한 손절**(거친 랭킹이 아니라). 박스저점 씨앗(IC+)을 살리려면.
- 단기는 본질적으로 어렵다는 걸 인정하고, 검증되기 전엔 비중을 아낀다.

### E. 【숨은 알파】 리스크 규율 자체가 엣지다
- 분기 전략이 시장보다 **낙폭이 작았다**(−17.5% vs −22.7%)는 게 핵심. 즉 *덜 잃는 것*만으로도
  복리는 크게 벌어진다. 비중관리·손절·장세규칙(상승장 추격 금지, 하락장 박스권)을 엔진으로.
- 투자 7계명(비중·손절·교차검증)은 장식이 아니라 *측정 가능한 알파*다.

### F. 【타임프레임 정합 아키텍처】
- **Track A 엔진** = 주봉/월봉 이평선 + 상대강도 + (초기)가속도, 3~6달 보유.
- **Track B 엔진** = 일봉/360분봉 박스저점 + 타이트 손절, 수주~1달.
- 같은 파동 수학을 *어느 타임프레임에 적용하느냐*로 두 게임을 분리(당신 철학).

### G. 【데이터 격차 메우기】
- 360분봉(단기)·상장폐지 포함 유니버스(생존편향)·재무/뉴스 과거(풀 buy_score 검증용).

## 🎯 결론 — 이게 멋진 알파 시스템이 될 수 있나?

**될 가능성을 오늘 처음으로 *데이터로* 봤다.** Track A의 "이평선 정배열+상대강도, 3~6달"은
시장을 이기는 *상대 우위*와 *더 작은 낙폭*을 보였고, 그게 하락장에서 더 강했다 — 이건
지속가능한 진짜 엣지의 모습이다. 남은 일은:
1. 그 엣지를 **생존편향·비용 제거 후에도** 진짜인지 확인(정직한 백테스트 인프라),
2. **무인 forward 루프**로 진짜 track record를 쌓고 두뇌를 자기교정,
3. **Track B는 별도 무기(인트라데이+박스+타이트 손절)**로 따로 증명,
4. **리스크 규율을 엔진**으로 삼아 *덜 잃어서 더 버는* 복리 계좌를 만든다.

핵심 마인드: **새 기능을 쌓기 전에, 이 검증 루프를 계속 돌려 "궁극의 밸런스"를 찾는 것**
(당신이 말한 그대로). 오늘은 그 첫 좌표를 찍었다 — Track A 본진 확인.

## 🧭 아키텍처 결정 — 결정론 후보층 먼저 강화 (2026-06-20 확정)

**질문**: 판단은 LLM이 하고 결정론 로직/지표가 "확률 높은 종목을 떠먹이는" 구조인데,
(A) 결정론 후보층(타이트한 조건·가드·지표)을 강화하나, (B) LLM을 다듬나?

**결정: (A) 결정론 후보층을 먼저, 더 *타이트하게* 강화한다. LLM 다듬기는 그다음.**

### 근거
1. **측정 가능성**: 결정론 개선은 **백테스트로 즉시 검증**(빠른 피드백). LLM 판단은
   **hindsight 때문에 백테스트 불가** → forward(몇 달)로만 검증. 측정 도구 있는 쪽에 먼저 투자.
   지금 LLM 손튜닝 = 눈 가리고 튜닝.
2. **천장은 후보층이 정한다**(garbage in/out): LLM은 떠먹여진 풀 안에서 고를 뿐. 후보의
   base rate가 시스템 품질 천장이고, 오늘 그 천장을 결정론으로 올릴 수 있음을 입증.
3. **측정된 엣지는 전부 결정론**: +8.7%p를 만든 건 정배열+상대강도. LLM 추가분은 미증명(가설).
   증명된 것 위에 쌓는다.

### "타이트하게"의 의미 (IC 발견 기반)
IC가 0 근처/음수 = 결정론 랭킹은 최상위에서만 실력. → **넓은 랭킹이 아니라 "좁고 확신 높은
최상위 슬라이스"를 떠먹여야** 한다. 단 **게이트가 아니라 메뉴** — 결정·거부는 여전히 LLM(결정론
게이트키핑 금지 원칙 유지). "타이트" = 후보 *생성*을 정밀하게, 결정을 경직되게가 아님.

### 강화 항목 (내일 인터뷰 후 착수)
| 종류 | 강화안 |
|---|---|
| 지표 | **타임프레임 정합** — Track A=주봉/월봉 이평선 정배열+상대강도 / Track B=일봉·360분봉 박스·레벨 |
| 조건(타이트) | **Confluence** — 정배열 AND 상대강도 상위 AND 신고가 추세 *초기* AND 이평 지지 동시충족만 후보 |
| 가드 | 장세 가드(상승장 추격 금지·하락장 박스모드) · 가속 *초기*만(블로우오프 배제) · 유동성 하한 · 손절선 없으면 탈락 |
| 검증 | 조건 추가마다 백테스트 A/B로 edge 상승 여부 즉시 확인 (이제 측정 도구 있음) |

### LLM의 차례
버리는 게 아님. LLM 가치 = 결정론이 인코딩 못 하는 것(뉴스·내러티브·regime 뉘앙스) + 거짓양성
거부. 단 **후보층이 탄탄해진 다음 + 무인 forward 루프로 track record 쌓으며 측정하면서** 다듬는다.

> 한 줄: **"확률 높은 종목을 떠먹이는 손을 더 정밀하게. 입(LLM)은 그다음에 길들인다."**

### ▶ 다음 세션(내일) 착수 — 결정론 가드·조건 보완
1. **인터뷰 먼저**: 사용자가 월/주/일봉별 **중요 이평선 조건 + 차트 모양(이미지 포함)** 을 던져줌.
2. 그걸 받아 **Track A/B 타임프레임 정합 지표 + confluence 조건 + 가드**를 결정론 후보층에 구현.
3. 각 조건을 백테스트 A/B로 검증하며 *타이트하게* 조여 고확신 슬라이스를 LLM에 떠먹이게.
