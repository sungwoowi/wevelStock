# 학습부: 자산복리부 (Wealth Compounding)

분석가 **자산전략가(wealth_strategist)** 가 읽는 자료.

10년·20년·그 이상 살아남으며 자산을 복리로 증식하는 다년 시각. 거시경제·통화·사이클·위기 인식·자산 보존 framework. 단기 시황(거시분석)을 넘어 **장기 생존 + 복리** 가 본질.

## 부서 정체성 (2026-06-10 재정의)

자산복리부 = **다년(10·20년) 거시 frame · 생존 · 변곡점 길잡이**.

- 현 자료(박종훈 framework + Ray Dalio 빅 사이클)는 "자산을 복리로 불리는 *전략*"(켈리·비중 증대·재투자 룰)이 아니라 **거시 세계관 frame** 이다. 복리 전략 자료가 생기면 별도 라운드에서 보강한다.
- 이 frame 은 설계상 보수적 — 절대 "매수" 를 말하지 않는다. 따라서 **평상시 트레이딩 판단의 방향 입력이 아니라 변곡점 (regime 전환 / DD 4건+ / 사이클 단계 변화) 에만 전면 반영**되는 길잡이다 (전략가 주입 게이팅이 결정론으로 강제).
- `market_macro`(시장매크로부) 와의 경계: 시장매크로부 = **일/주 단위 시황** (regime 6단계·breadth·DD), 자산복리부 = **다년 사이클·통화·시대 위치**. 시계가 다르다.
- 오른쪽 뇌 `WEALTH-COMPOUND-TRACKER-001` (자산 곡선 추적, `/wealth`) 은 **성과 측정**이며 이 부서와 무관 — "복리" 워딩 충돌 회피를 위해 그쪽은 "자산 곡선/자산 성장" 으로 표기.

## 자료 운영 흐름

- **canon/wealth_compounding/** (이 폴더): "변하지 않는 framework" 의 압축 정제본. LLM 매 호출마다 주입.
- **reference/wealth_compounding/**: 원본 PDF 추출본 (예: 박종훈 강의·전자책). LLM 비주입, RAG 인덱싱 대상.

자료가 점진 추가되는 학습부 (예: 진행 중인 강의). 정제본은 framework 변동 시에만 손글로 갱신, 디테일·시기 전망은 RAG 가 동적으로 retrieve.

자료 채우기는 M2.5 (RAG SPEC + ingest) 와 함께 진행.
